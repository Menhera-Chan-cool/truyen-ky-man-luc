# Shared heading fonts

User confirmed: one heading-font choice for the whole book, independently for VI and EN. Owner/editor can add/remove shared fonts; readers cannot change the author’s heading style. Existing headings remain the default. Register the supplied FZ Thư Pháp Tiểu Tự as the second choice, preserving its source file and attribution.

Use optional `BookMeta.headingFont` (`default` or a registered UUID), carried by existing draft/publish/CAS metadata. Apply only to chapter titles and h1–h4 in text content, rich/HTML preview, comparison and offline reading. Body fonts, UI labels, chapter text/revisions, annotations, TTS text and PDF page typography remain unchanged.

Add a small private Supabase font catalog/bucket. Font uploads go directly to Storage (TTF/OTF/WOFF/WOFF2, existing 3MB limit), browser-decode validation and server signature/size/container checks. Registered paths are immutable. Default cannot be removed. Removing a custom font archives it; reject removal if either saved draft/published VI/EN metadata still uses it, with a book-row lock shared with metadata saves. Old font files are retained. New metadata cannot reference unknown/archived fonts. Guest font reads are allowed only when selected in published metadata; editors may preview private fonts. Validate membership on server and enforce RLS/direct API grants. No public registration or new dependency.

Editor has add/remove controls, VI/EN selectors, selected-font preview and clear save/publish guidance. Font files load only when selected; failures fall back to the current font. Dynamic CSS uses only canonical UUIDs and fixed URLs, never arbitrary CSS/URLs from input. Offline snapshots include selected published fonts. Existing metadata without the field stays valid.
