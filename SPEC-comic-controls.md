# Comic reader controls

User requests Comix-like reader behavior on PC/mobile. Explicit requested behavior wins where the current reference differs. The Firecrawl interact workflow was verified with short Node/Playwright commands, a known scrapeId, sequential sessions and explicit stop; broad multi-step prompt calls timed out and temporarily occupied the two-session limit. No plugin permissions/configuration changes were needed. On Comix, desktop double-click and touch double-tap toggle chrome, hidden state survives chapter navigation, and mobile hides stretch/zoom. The inspection did not reproduce automatic hiding at 10 seconds, and upper-right hover sometimes exposed the lower toolbar too; implement the user's explicit 10-second and independent-group requirements.

- A new tab opens with all chrome visible, then hides after 10 seconds. Keep current visibility across comic chapters, language navigation, Back/reload in the same tab. Restore before exposing controls to avoid flashing visible chrome on hidden chapter transitions; handle unavailable storage without a crash.
- Wheel, scroll, pointer motion over content, single tap, swipe, and returning to a background tab do not reveal all chrome. Auto-scroll still stops on manual navigation/backgrounding.
- Double click/tap on reading images or blank space toggles all chrome. Do not treat drags, pinch, modal controls or links as double taps. Disambiguate horizontal edge taps so a double tap does not advance pages.
- Hidden desktop UI reveals only the hovered/focused region: left progress, upper-left edition menu, upper-right chapter/tools, lower-right stretch/zoom. Leaving it hides it; no global wake. Keep keyboard focus visible, dialogs usable, and an accessible explicit reveal action.
- Mobile has no hover reveal and no stretch/zoom percentage toolbar. Use fit-width image sizing, retain desktop preferences when resizing, and preserve native pinch zoom. Touch targets remain accessible.
- Preserve approved graphite/cyan design, original images, publication/auth/RLS, reading progress and settings. No database change or dependency. Update help and existing tests that expected old pointer/scroll wake or a 3-second timer.
